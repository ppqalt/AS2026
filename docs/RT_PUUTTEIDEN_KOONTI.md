# Puuttuvien RT-asemien koonti

Avaa Kilvet → Toiminnot → Puuttuvien RT-asemien koonti.

Koonti näyttää koko kilpailun puutteet ryhmiteltyinä radan, jakson ja RT-tunnuksen mukaan. Puutteita-sarake laskee puuttuvat merkinnät; Pareja-sarake laskee eri kilpailuparit. Sama pari voi puuttuvan tunnuksen toistuessa tuottaa useamman puutteen, mutta kuuluu parimäärään vain kerran.

Kilpailunumerot näkyvät taulukossa. Valitse rivi nähdäksesi numerot myös kokonaisena luettelona taulukon alapuolella. Pitkää luetteloa voi vierittää.

Koonti perustuu kilpailutiedostoon tallennettuihin vastaanotettuihin kirjauksiin, myös keskeneräisten parien jo tulkattuihin jaksoihin. Yläosassa näkyy, kuinka monelta parilta kirjauksia on vastaanotettu. Avoin koonti päivittyy uusien kirjausten ja korjausten mukana.

Jos parilta on kirjattu vain puuttuvien RT-asemien määrä tai käsin muutettu määrä ei vastaa tunnusluetteloa, määrä näkyy rivillä Yksilöimättä. Ohjelma ei arvaa puuttuvien asemien tunnuksia.

Sulje ikkuna Sulje-painikkeella tai Esc-näppäimellä.
