# AS2026 0.7.9

AS tulkin tulkintojen vastaanotto jatkuu, vaikka palvelimelle tallennetun
tulkinnan historiassa olisi tyhjä virhepistekenttä. Avaa sama kilpailu ja
päivitä tulkinnat. Ohjelma noutaa aiemmin tallennetut tulkinnat uudelleen
viimeisestä onnistuneesta tallennuskohdasta.

Pura koko käyttöjärjestelmäsi paketti. Käynnistä Windowsissa
**as2026-gui.exe** tai Linuxissa **as2026-gui**.
